Cộng Đồng Game Thủ

Là địa chỉ số 1 cung cấp các dòng Gaming Phone chuyên dụng (ROG Phone, RedMagic) cùng hệ sinh thái phụ kiện quạt tản nhiệt, tay cầm chơi game đỉnh cao.

Thông Tin Đồ Án Môn Học

Dự án được xây dựng phục vụ bài tập Assignment môn Lập trình JavaScript Nâng Cao tại FPT Polytechnic.

  • Kiến trúc SPA (Single Page Application) hiện đại kết hợp CSS Cyber/Gaming Design System.
  • Cơ sở dữ liệu mô phỏng chuẩn RESTful API với json-server.
  • Quản lý đầy đủ luồng nghiệp vụ E-Commerce: Danh mục 8 hãng, 40 sản phẩm, Lọc theo giá, Lọc theo hãng, Giỏ hàng, Đặt hàng trừ tồn kho, So sánh 10 cấu hình, Đăng nhập/Đăng ký và Trang Quản trị Admin chuyên biệt.
